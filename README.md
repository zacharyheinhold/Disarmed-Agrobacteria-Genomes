# Disarmed Agrobacteria Genomes

Collection of annotated disarmed agrobacteria strain genomes.

Genomic DNA was isolated using the Promega Wizard Kit (https://www.promega.com/products/nucleic-acid-extraction/genomic-dna/wizard-genomic-dna-purification-kit/?tabset0=0) and sequenced using Plasmidsaurus (https://plasmidsaurus.com/) bacteria whole genome sequencing using Oxford Nanopore long reads (https://nanoporetech.com/).

Genomes were assembled from raw reads using Geneious (version 2026.0) with parameters __________.

Genomes were annotated using the beav pipeline (https://github.com/weisberglab/beav).

Disarmed agrobacteria strains are available by request (https://biotechlab.forestry.oregonstate.edu/).
